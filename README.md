# AI Data Scientist Copilot

An enterprise-style analytics platform built using Python, Streamlit, Pandas, Plotly, and Scikit-learn.

## Features

- Dataset Upload
- Data Quality Checks
- Data Cleaning
- Exploratory Data Analysis (EDA)
- Machine Learning (Regression)
- AI Business Insights
- AI Dataset Assistant (Natural Language Q&A)
- Downloadable Reports

## Tech Stack

- Python
- Streamlit
- Pandas
- NumPy
- Plotly
- Scikit-learn

## Run Locally

```bash
pip install -r requirements.txt
python -m streamlit run app.py
```

## Example Dataset

Works with supermarket sales, retail sales, and other sales datasets from Kaggle.
